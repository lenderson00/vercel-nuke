Conectar

Cole um token de acesso da Vercel. Ele serve para ler e apagar os recursos da conta.

Crie um token de curta duração em vercel.com/account/settings/tokens. Escolha validade de 1 hora, assim ele expira sozinho depois do uso.

Como funciona

O token fica só neste navegador, no localStorage. O botão "Esquecer token" apaga ele daqui.

As chamadas saem do seu navegador direto para api.vercel.com. Não existe servidor no meio, nem coleta de uso.

A página é um arquivo HTML só. Você pode baixar, abrir no seu computador e ler o código antes de usar.
